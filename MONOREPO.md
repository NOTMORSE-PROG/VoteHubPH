# VoteHubPH monorepo

VoteHubPH already had an aggregate repository. This branch connects the
complete histories of the three component repositories and synchronizes their
latest committed trees.

- Canonical GitHub URL: https://github.com/NOTMORSE-PROG/VoteHubPH
- `frontend/` source:
  https://github.com/NOTMORSE-PROG/VoteHubPH_Frontend
- `backend/` source:
  https://github.com/NOTMORSE-PROG/VoteHubPH_Backend
- `admin/` source:
  https://github.com/NOTMORSE-PROG/VoteHubPH_Admin

The backend retains its Railway configuration and the frontend retains its
Vercel configuration. No provider project, domain, alias, repository, or URL is
renamed. The three source repositories remain available for rollback.
